LLM Gateway

OpenAI-compatible gateway in front of OpenAI, Anthropic and Ollama: virtual keys with budgets and rate limits, weighted routing with retries, fallbacks and circuit breakers, response caching, and usage and cost reporting.

Source on GitHub Open in Codespaces Deploy to Render

This page is a static API reference built from the gateway's exported OpenAPI document on every push to main; there is no backend behind it, so requests cannot be sent from here. The Codespace runs the real gateway with PostgreSQL, Redis and the offline fake providers, sends demo traffic and opens the usage dashboard below; Render deploys your own copy.
